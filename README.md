# ChocoCooper's Repo

This repository contains custom CloudStream providers for accessing and organizing media from various online sources. The extensions are designed to work with CloudStream.

New providers may be added, and existing providers may be updated over time.

## Install Repo

[![Install](https://img.shields.io/badge/Install-CloudStream-blue?style=for-the-badge)](cloudstreamrepo://raw.githubusercontent.com/ChocoCooper/cloudstream-repo/master/repo.json)

If the button does not work, add the repository manually in CloudStream:

```text
https://raw.githubusercontent.com/ChocoCooper/cloudstream-repo/master/repo.json
```
