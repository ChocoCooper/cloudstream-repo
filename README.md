# ChocoCooper's Repo

This repository contains custom [CloudStream](https://github.com/recloudstream/cloudstream) providers for accessing and organizing media from various online sources. The extensions are designed to work with CloudStream.

New providers may be added, and existing providers may be updated over time.

## Install Repo

CloudStream → Settings → Extensions → Add Repo

```text
https://raw.githubusercontent.com/ChocoCooper/cloudstream-repo/master/repo.json
```
